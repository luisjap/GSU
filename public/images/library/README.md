# GSU — Biblioteca de imágenes corporativas

115 imágenes generadas bajo Style Lock (ver `docs/design/image-style-lock.md`).

- **Fase 1** (20): Home, Servicios, Nosotros, CTA, Contacto — v1, aprobada
- **Fase 2** (28): Sectores/Arquitectura, Proceso, Mantenimiento, Seguridad, Macro, Infraestructura — v2, aprobada
- **Fase 3** (28): Blog, Casos ilustrativos, Emergencias, Proyectos — v2.1, aprobada
- **Fase 4** (38): Heroes, Landing, Redes sociales, Banners, Texturas, Detalles premium, Smart Maintenance, Cliente/administrador — v2.2, aprobada

`manifest.json` — metadata por imagen (categoría, página, orientación,
ratio, plano, personas, industria, contenido, colores dominantes, prompt,
versión). Ver `docs/design/image-map.md` para la asignación de cada imagen
a su lugar en el sitio.
